# 词句修订

一款给 SillyTavern（酒馆）用的本地词句修订插件，用来清理 AI 回复里看腻的口癖、八股句式、错称呼，也支持手动清理角色卡、世界书和 User 人设里的文字。

纯本地按规则运行，**不调用 AI、不耗额度、不上传聊天内容**。修改会直接保存回酒馆，并且支持撤销。

## 安装与打开

1. 在酒馆打开 **扩展 → 安装扩展**。
2. 粘贴安装地址并安装：`https://github.com/Mint0oO/sillytavern-text-revision`
3. 安装完成后刷新页面（需 SillyTavern 1.13.5+，电脑和手机都能用）。

装好后，任选一种方式打开面板：
- 点击输入框左侧的 **魔棒 → 词句修订**，或直接发送 `/text-revision`
- 点击任意一条 AI 回复编辑铅笔左侧的 **方框铅笔图标**，直接检测那一楼
- 在插件「设置」中开启 **显示悬浮球**，随时轻点打开（可拖动位置）

## 怎么用

打开面板后，顶栏就是全部功能：**主页面（正文修订）**、**角色**、**规则**、**记录**、**设置**。

### 1. 修订正文（主页面）

默认开启自动检测和人工审查。AI 回复完后，命中规则的句子会自动列出来给你挑；不想自动弹可以在「设置」里关掉自动检测，需要时再手动打开。

- **一眼看懂改动**：<del>删除线</del> 是要删的字，**绿色**是替换后的字，**黄色**是需要手动改的地方。
- **按需勾选**：点击整条即可选中或取消，不想改的句段取消勾选就不会动。
- **顺手微调**：点右上角 **铅笔** 可直接改整句（展开「替换候选」还能点「换一个」切别的随机词）；点右上角 **`…`** 可快速「恢复」原句或「删除」整句。
- **保存与撤销**：点 **应用所选** 写回正文，改错可点 **撤销**；这楼都不想动就点 **完成审阅**。顶部 **重新检测** 只会重扫当前这一楼。

### 2. 写规则（「规则」）

点 **新增**，主要就填 **查找** 和 **替换为** 两个框，填完点 **试一下** 就能贴句台词看效果。

因为默认是人工审查，**规则可以写得很宽松**，平时直接填汉字就行，不用一上来就学复杂正则：

| 常见需求 | 查找 | 替换为 | 说明 |
| --- | --- | --- | --- |
| 删掉口癖 | `猛地` | 留空 | 替换留空就是删除 |
| 固定替换 / 改错称呼 | `御膳房` | `内膳房` | 把错词或旧称呼直接换掉 |
| 多词合并 / 随机替换 | `极其, 极度, 至极` | `很, 十分` | 英文逗号或换行分项，多个替换词会随机抽 |
| 带不带字尾都抓 | `死死地?` | 留空 | `?` 表示前面那个字可有可无 |
| 抓复杂句式（可选） | `不是([^，。！？]+)，而是([^。！？]+)` | `$2` | 查找支持 JS 正则，`$1`/`$2` 保留括号内容 |

几个顺手的小细节：
- 查找和替换都用 **英文逗号 `,` 或换行** 分隔多项，中文逗号正常当标点；如果替换词本身含英文逗号，用英文双引号包住（如 `"轻轻, 缓缓", 低声`）。
- 替换内容支持 `{{user}}`、`{{char}}`、`{{random::轻轻::缓缓}}` 等酒馆宏。真想抓复杂句式但不会写正则，让 AI 写一条 JS 正则贴进「试一下」测过就行。
- 规则多了可以 **＋ 新建分组** 整组开关；非常放心的规则可以给单条或整组设为 **自动应用**，以后回复完会自动静默改好（优先级：**单条 > 分组 > 设置页默认**）。多条规则撞在同一处时，按规则里的 **高 / 中 / 低** 优先级裁决。
- 顶栏右侧图标支持 **导入 / 导出 JSON**，方便备份或分享规则（仅含规则和分组，不含聊天记录）。

### 3. 修订角色卡与人设（「角色」）

用来批量清理当前角色的 **角色设定**、绑定 **世界书**、**指令与元信息** 和 **User 人设**。全程纯手动触发，不会自动改动原卡，写回后同样支持本轮 **撤销**。

- **自由选范围、顺手看原文**：勾选框控制是否检测；点击类目行可展开挑具体条目（世界书支持按蓝灯 / 绿灯 / 向量及「仅已启用」筛选）；点击条目名可直接弹窗查看并修改原文。
- **独立角色规则**：底部 **角色规则** 单独管理只给角色卡用的规则，默认同时勾选「正文规则」——展开后可按组或单条独立开关（不影响正文那边），随时可点 **正文规则恢复默认** 同步回去。
- 平时不用这个功能时，在「设置 → 运行设置」关闭 **启用角色修订** 即可隐藏顶栏入口。

### 4. 记录与设置（「记录」「设置」）

- **记录**：按楼层和回复版本（如 `10# 1`）保留本聊天的检测与修改日志，只存在当前聊天元数据中，不会发送给模型。
- **设置**：
  - **运行设置**：管理插件开关、自动检测、启用角色修订、显示逐楼层检测入口、默认处理方式（人工审查 / 自动应用）。
  - **检测范围**：配置 **标签提取**（如填 `content` 只查 `<content>...</content>` 内，留空查全文）和 **内容排除**（默认已排除 `<think>`、`<thinking>`，状态栏如 `<status>` 到 `</status>` 可自行添加；排除优先于提取）。
  - **界面外观**：切换 **极简 / 暖纸 / 青雾 / 淡紫** 风格、日夜间、背景透明度、三组修订配色（经典 / 柔和 / 鲜明）以及悬浮球样式。
