# 正文修订

适用于 SillyTavern 的纯规则正文修订扩展。回复输出结束后检测指定词语和句式，按正文顺序展示修改建议，由你选择、手动编辑和应用。**不调用 AI，也不需要 API Key。**

## 安装

1. 在电脑或手机的酒馆中，打开「扩展」→「安装扩展」。
2. 粘贴 `https://github.com/Mint0oO/sillytavern-text-revision`，完成安装后刷新酒馆。
3. 点击右侧悬浮的「修订」。也可从扩展设置打开，或输入 `/text-revision`。

需要 SillyTavern 1.13.4 或较新版本，以及支持原生 dialog 的现代浏览器。若酒馆没有「安装扩展」，需要服务器管理员允许扩展安装；不需要在手机上安装 Node.js。

## 使用

- 生成完成后自动检测，不自动应用，不打断阅读。悬浮按钮显示待处理数量。
- 句子右侧的小铅笔用于编辑整句，勾选框用于选择是否应用。
- 「删除」与替换词分开；「换一个」只选择其他替换词。
- 默认勾选有可应用建议的句子；取消勾选的句子不会改动。「应用所选」一次处理全部勾选项。
- 应用直接更新 `chat[].mes` 和当前 `swipes[swipe_id]`，调用酒馆保存，再读取服务器聊天核对。后续请求使用修改后的正文；其他版本不变。
- 「撤销」恢复本轮最近一次应用。切换聊天、回复版本、外部编辑或重新检测后，过期结果不能覆盖当前正文。
- 「记录」以检测轮次保存初始问题数、句子数与处理数。每个聊天最多保留 30 轮，较大记录会更早清理旧轮次；累计轮数继续保留。
- 「规则」设置固定词语、替换词（每行一个）、是否允许删除，以及默认删除／随机替换／仅待改。关闭勾选可停用规则。保存规则后，下次检测生效。
- 「设置」支持日间、夜间、三组配色与背景透明度。透明度不改变文字透明度。

## 句式范围

`像{A}的孤狼一样` → `{A}` 可以提出「他已经看透生死。」这样的建议。`像{A}一样` 在句中可以建议删掉比喻段；在句末会保守地标为待改，避免只留下主语。

这些是有限模板，不理解句意。即使改后通顺，也可能丢失信息。应用前请检查，必要时编辑整句。「不是 A，而是 B」默认保留 B 也会删掉否定信息，可以在规则中改为其他候选或仅待改。

自动检测跳过代码块、行内代码、常见思考标签、HTML 标签属性和 Markdown 链接目标。单次检测限制为 20 万字符、200 条规则、1000 处匹配；超过时给出提示，不截断正文。

## 数据与兼容

规则和外观保存在酒馆扩展设置，检测记录和原文快照保存在当前聊天元数据；这些记录不作为正文传给模型。导出聊天文件时会一并导出记录。原文快照用于对比和撤销，并非加密备份。

扩展没有外部服务、跟踪脚本、远程字体或模型请求。唯一额外网络请求是向你自己的酒馆读取已保存聊天进行核对。手机通过局域网 HTTP 访问时也能生成内部记录编号。

如果出现「未能确认保存成功」，请先检查网络。服务器可能已收到保存但核对请求失败；这时刷新聊天查看实际结果，再重新检测。扩展不会把无法确认的保存报告为成功。

同一聊天在多个设备同时编辑仍可能发生酒馆自身的并发冲突。建议只在一个设备上修改当前聊天。世界书、摘要、其他插件已缓存的旧内容不会被本扩展重写。

## 开发验证

无构建步骤、无运行依赖。仓库根目录的 manifest.json 可直接被酒馆安装。

```sh
npm test
npm run check
node scripts/dev-server.mjs
```

最后一个命令打开本地模拟酒馆界面：`http://127.0.0.1:8788`。模拟器可测试自动检测、保存、刷新读取、上下文正文和失败提示；它不是完整酒馆实例。`dev/` 与 `tests/` 不会由扩展入口加载。

接口依据：[酒馆扩展文档](https://docs.sillytavern.app/for-contributors/writing-extensions/)、[上下文接口](https://github.com/SillyTavern/SillyTavern/blob/release/public/scripts/st-context.js)。
